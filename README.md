## Управление таблицами

Встроенный модуль базы данных позволяет создавать, просматривать и удалять
таблицы. Структура таблиц (метаданные) сохраняется в файл `db_meta.json`,
поэтому таблицы **не теряются между запусками** программы.

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти из программы |

**Поддерживаемые типы данных:** `int`, `str`, `bool`.

> Столбец `ID:int` добавляется автоматически первым — пользователю его
> задавать не нужно.

### Пример использования

    >>>Введите команду: create_table users name:str age:int is_active:bool
    Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

    >>>Введите команду: create_table users name:str
    Ошибка: Таблица "users" уже существует.

    >>>Введите команду: list_tables
    - users

    >>>Введите команду: drop_table users
    Таблица "users" успешно удалена.

    >>>Введите команду: drop_table products
    Ошибка: Таблица "products" не существует.

    >>>Введите команду: exit

## CRUD-операции

После создания таблицы доступны команды для работы с записями.
Синтаксис команд похож на SQL.

### Create — создание записи

```text
insert into <имя_таблицы> values (<знач1>, <знач2>, ...)
```

Добавляет новую запись. Значения перечисляются **без учёта `ID`** — он присваивается автоматически.

```text
>>> insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
```

### Read — чтение записей

**Все записи таблицы:**

```text
select from <имя_таблицы>
```

**Записи по условию:**

```text
select from <имя_таблицы> where <столбец> = <значение>
```

```text
>>> select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
```

Если подходящих записей нет, выводится `Записи не найдены.`

### Update — обновление записей

```text
update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>
```

Изменяет указанный столбец во всех записях, подходящих под условие `where`.

```text
>>> update users set age = 29 where name = "Sergei"
Записи в таблице "users" обновлены (затронуто: 1).
```

Если таких записей нет — `Записи для обновления не найдены.`

### Delete — удаление записей

```text
delete from <имя_таблицы> where <столбец> = <значение>
```

Удаляет все записи, подходящие под условие `where`.

```text
>>> delete from users where name = "Sergei"
Записи удалены из таблицы "users" (удалено: 1).
```

Если таких записей нет — `Записи для удаления не найдены.`

## Правила записи значений

| Тип | Как записывать | Пример |
|---|---|---|
| `int` | число без кавычек | `28`, `-5` |
| `str` | строку **в кавычках** (одинарных или двойных) | `"Sergei"`, `'Anna'` |
| `bool` | `true` / `false` без кавычек | `true` |

Дополнительно:

- значения в `insert ... values (...)` разделяются запятыми;
- условие `where` и блок `set` поддерживают **одно** условие `столбец = значение`;
- регистр ключевых слов не важен.
